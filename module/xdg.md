# `xdg`

`xdg` is a shared set of standards for interaction with desktop environments on POSIX. For now, we provide `module/xdg/mimeapps.list -> ~/.config/mimeapps.list` which declares default applications corresponding to mime types.

On Debian, we use `ungoogled-chromium.desktop`. On Arch, we use `chromium.desktop`. This can probably be patched, to Debian pref.
